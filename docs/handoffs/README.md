# Handoff notes

One file per work package from `docs/implementation-plan.md`: `WP-<id>.md`. Each agent keeps its file current on
its branch (committed and pushed at every milestone), so another harness or account can resume the work.

Each file has: status (not started / in progress / PR open / merged), branch and worktree, PR number, what is done,
what is left (as a checklist), how to run the WP's tests, decisions and dead ends, and the exact next step.
